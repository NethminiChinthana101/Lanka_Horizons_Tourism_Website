# Lanka Horizons — Sri Lanka Tourism Website

A polished multi-page tourism website built with plain HTML, CSS and JavaScript.

## Pages
- `index.html` — Home
- `about.html` — Our Story
- `destinations.html` — Destinations
- `tours.html` — Tour listing + filters
- `tour-island-highlights.html`
- `tour-culture.html`
- `tour-wild.html`
- `tour-south.html`
- `contact.html` — enquiry form

## Run
No build step is required. Open `index.html` in a browser.

## Notes
- Images are loaded from Unsplash URLs, so an internet connection is needed for the photos and Google Fonts.
- The contact form is front-end demo only and does not send email.
- Replace the demo brand name, phone, email, prices and images with your real business information.
